Aaaj maine JavaScript me Form Validation orr Button Click Events ke baare me seekhaa. Iss task me maine ek simple form banayaa jiisme user apna name orr email add kartaa  haii orr phir Submit button pee click karta haii.Sabse pehle maine HTML me do input boxes banaye ek name ke lia orr ek email ke lia orr ek button jiska id “submitButton” rakha. Phir maine JavaScript me onclick event use kiiya taake jab user button pe click kare too validateForm() function run ho.Function ke andar maine getElementById se user ke likhe hue values lie orr unhe check kiya. Agar dono me se koi field khaali hoti hai to message me red color me warning show hoti hai “Please fill all fields”. Lekin agar dono boxes me value hoti hai to green color me message aata hai “Form submitted successfully”.Is task se maine seekha ke JavaScript ke zariye hum user input ko check (validate) kar sakte hain orr onclick event se koi bhi function run karwa sakte hain.
