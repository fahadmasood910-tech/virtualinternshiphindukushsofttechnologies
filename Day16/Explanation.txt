Day16:

Aaaj maine ek simple HTML page banaya jiisme JavaScript use kaarke apna Name, Age orr Hobby define kiya. Saabse pehlee maine let keyword kaa use karke teen variables banayan Name, Age orr Hobby. In variables ke andar maine apna personal data store kiya jaise Name = "Fahad Masood" Age = 20 orr Hobby = "Cricket". In steps se maine yah sekha ke JavaScript me data ko variables ke zariye kaise store kiya jaata haii.
Uske baad maine console.log() ka use karkee yeh sab values browser ke console me print kii.  Jab page ko open kar ke console check karenge toh user ko Name, Age orr Hobby clearly show hote haiin. Is  practice se maine yeh sekha ke console ka role sirf output dikhana  nahi balki debugging me bhi help karna haii.
Finally maine alert() function kaa use kiya jisme ek message display kiaa hai “Aaj ka task pura huwa Name , Age orr Hobby dekhne ke lia console open karian.” Yeh ek popup ke form me user ko instruction deta haii ke console open karke apna data dekheiin. Isse maine yeh sekha ke JavaScript me alert() directly user ke saamne ek notification ya message dikhane ke liye use hota hai.Too aaj ke  task se maine seekha ke variables kya hote hain, unko kaise declare orr use karte haiin console me data kaise print karte haiin orr alert box kaise banate haiin.
