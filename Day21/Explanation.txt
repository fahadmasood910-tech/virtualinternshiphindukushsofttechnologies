Aaaj maine JavaScript me DOM (Document Object Model) kee zariiye HTML elements koo change karna seekhaa. Iss task me maine eik chhota project banaya jisme heading aur paragraph ka content button click karne se change hota hai.Sabse pehle maine eik variable (showingMoon) banaya jo track karta haii ke abhi page pe Moon ka content show ho raha hai ya Sun ka. Phiir maine eik function changeContent() banaya jisme maine getElementById("heading1") se heading lee orr querySelector(".paragraph") se paragraph select kiya.Uske baad maine if else condition lagayaa agar showingMoon true ho to page pe “The Sun” ka heading aur uska paragraph show hota hai warna “The Moon” wapas aa jata haii. Button ka text bhi accordingly change hota hai “Change to Sun” orr “Change to Moon”. Iss project se maine seekha kee JavaScript kee through HTML elements kaaa text orr structure real time me change kiiiya jaa sakta haooi orr ye hi DOM ka main concept haiii. Yah task simple tha orr is see maine yah samjha ke web pages ko interactive orr dynamic kaiise banaya jata haiii.
