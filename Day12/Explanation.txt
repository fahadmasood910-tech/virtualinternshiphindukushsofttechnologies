Aaj humne seekha ke 3 column gallery kaise banayee jati hai. Gallery ka matlab hota hai ek jagah multiple images ko neat aur stylish tarike see dikhana. Humne yeh samjha ke agar hum kehte hain 3 column gallery too iska matlab haii ek row me 3 images side by side hoon.Too humne CSS Grid ka use kiya jisme grid responsive ban gayi  yani badii screen par 3  images side by side aa gayee oor chhoti screen par 1 ya 2 images aa rahi hain.Iske liye humne display grid aur grid template columns ka use kiyaa. Hum nee repeat(3,1fr) likha jisse columns ke tedad 3 ho gayii . Saath hi humne gap property use ki jisse images ke beech me proper spacing aa gaye.Images hum nee picsum.photos website se liye jo random placeholder images deti hai practice ke liye. Oor hover effect bhi add kiya jisse jab image par mouse le jaate hain too wo thoda zoom hota hai oor ziada attractive lagta  haii.
